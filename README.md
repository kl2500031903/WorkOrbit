# WorkOrbit (React)
npm install && npm run dev
Demo admin: admin@task.com / admin123. Uses localStorage keys users, tasks, currentUser (same as your JS files).

## Features
Login/Signup (validation + error messages), session kept in localStorage after refresh, user dashboard (add / edit / complete / delete / share / filter / drag-drop), admin dashboard (stats, users, tasks, delete), deployed on Vercel.
